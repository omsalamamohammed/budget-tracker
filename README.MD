# My Budget Tracker

## Project Description
My Budget Tracker is a simple website that helps users record and organize their daily expenses.

## Files
- `index.html` — Contains the webpage structure, expense form, expense table, image, video, and help section.
- `style.css` — Controls the website's colors, layout, table styling, and other visual effects.
- `README.md` — Describes the project and its features.

## Features
- Expense form with name, amount, category, and date fields.
- Category options: Food, Transport, Rent, Entertainment, and Other.
- Expense table with five sample records.
- Image and budgeting video.
- Collapsible help section.
- Table row hover effects and advanced CSS selectors.

## Technologies Used
- HTML5
- CSS3

## How to Run
Open `index.html` in a web browser.

## Current Limitation
The Add Expense button does not add new expenses yet. JavaScript functionality can be added in a future lesson.
